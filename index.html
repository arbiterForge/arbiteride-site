The governed agentic IDE.

You state the intent. The agent does the work. Nothing reaches your default branch until every gate has cleared — and you can read exactly which ones did.

Intent→ Gates→ Verified pull request

What it is

Built on Eclipse Theia

A real desktop IDE, not a chat window bolted to an editor. Open source foundations, familiar surface.

Governed by codeArbiter

The same gates, reviewer fleet, and audit trail that already run in the terminal — wired into the editor.

A PR you can defend

Every change arrives with the tests, reviews, and decisions that let it through, recorded rather than asserted.

Not yet available. arbiterIDE is in active development and there is no download or preview build to sign up for. If you want the governance model today, it already ships for Claude Code, Codex, and Pi.
