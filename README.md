# arbiteride-site

Splash page for **arbiteride.com**.

A single self-contained `index.html` — no build step, no dependencies, no external requests.
Published to GitHub Pages from the default branch; `CNAME` binds the custom domain.

The product itself lives in the private `arbiterForge/arbiterIDE` repository. This repo exists
only so the marketing page can be public without making that one public.
